# Bear Precious(クマ型：プリティ)

## 概要
アプリゲーム「nieR Re[in]carnation」に出てくるオトモ「クマ型：プリティ」の3Dモデルを表示し、アニメーションさせる3D viewerです。

- 2024年4月30日にサービスを終了したゲームに登場するオトモの二次創作として作成しています。
- オトモをクリックするとアニメーションが開始され、もう一度クリックするとアニメーションが停止します。
- 営利目的で作成していません。

## 公開URL
https://bear-precious.inxole.jp/

## インストール方法
### 必要な環境
- node.js v24.18.0
- yarn 4.18.1

### 手順
1. node.jsとyarnをインストール
2. パッケージをインストール
```bash
$ yarn install
```
3. ローカルで確認
```bash
$ yarn dev
```
